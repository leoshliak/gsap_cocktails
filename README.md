# 🍸 Cocktails — Animated Landing Page

A modern and vibrant cocktails landing page built with **React**, **Tailwind CSS**, **JavaScript**, and **GSAP**.  
The site is packed with smooth animations and scroll-triggered effects for an immersive experience.  

🔗 **Live Demo:** [gsap-cocktails-theta-olive.vercel.app](https://gsap-cocktails-theta-olive.vercel.app/)
